# 系杆拱桥立面几何参考

供 `generate_tied_arch_sketch.py` 取值与校核时查阅。所有规范条文均标注来源，可回溯核验。

---

## 1. 拱轴线方程

脚本的 `--axis` 参数对应下列方程。设拱净跨 `L`、矢高 `f`，拱脚在 `L_FOOT` 标高，
`t = (x − x_c)/(L/2)`（`x_c` 为拱跨中心，拱顶 `t=0`、拱脚 `|t|=1`）。

| `--axis` | 方程 | 说明 |
|---|---|---|
| `parabola` | `y = L_FOOT + f·(1 − t²)` | 二次抛物线。系杆拱、简支系杆拱最常用 |
| `power` | `y = L_FOOT + f·(1 − \|t\|ⁿ)` | 幂函数，`n` 由 `--axis_n` 给定；`n=2` 即抛物线，`n<2` 更饱满 |
| `catenary` | `y = L_FOOT + f − f/(m−1)·(cosh(k·\|t\|) − 1)`，`k = arccosh(m)` | 悬链线。`m` 为拱轴系数（`--cosh_m`），拱顶平缓、拱脚最陡；`m→1` 退化为抛物线 |
| `circle` | `R = (L²/4 + f²)/(2f)`；`y = L_FOOT + √(R² − x²) − (R − f)` | 圆弧线，小跨径或坛工拱常用 |

> 悬链线的标准形式为 `y = f/(m−1)·(ch k ξ − 1)`，其中 **ξ 为自拱顶量起的相对水平距离**
> （拱顶 ξ=0、拱脚 ξ=1），`y` 为自拱顶向下的竖向距离 → 换算成自拱脚向上的标高即上表形式。
> `m` 的物理含义是拱脚与拱顶的恒载集度之比，常用 1.167 ~ 2.814；`m=1.167` 时接近抛物线。
> **易错点**：若把 ξ 写成"自拱脚量起"，拱顶会变成尖顶、拱脚反而平缓，形状完全反了。

## 2. 矢跨比取值（按规范 / 教材）

矢跨比 `f/L` 是拱桥最关键的总体参数：矢跨比越小（越坦），水平推力越大、对主拱受力有利
但对墩台基础不利；弹性压缩、收缩徐变、温度与基础变位引起的附加内力也越大。

| 桥型 / 体系 | 矢跨比常用范围 | 来源 |
|---|---|---|
| 钢管混凝土拱桥主拱 | 宜为 **1/3.5 ~ 1/6.0** | 《钢管混凝土拱桥设计施工与养护规范》7.1.2 |
| 拱梁（系杆）组合桥 · **中承式** | 一般可取 **1/3.5 ~ 1/6** | 《桥梁工程》教材 A3-3.13 |
| 拱梁（系杆）组合桥 · **下承式** | 一般可取 **1/5 ~ 1/10** | 《桥梁工程》教材 A3-3.13 |
| 拱梁（系杆）组合桥 · 上承式 | 一般可取 1/6 ~ 1/12 | 《桥梁工程》教材 A3-3.13 |
| 柔性系杆刚性拱 | 一般 1/5 ~ 1/4 | 科普中国 / 百科「系杆拱桥」条目 |
| 刚性系杆柔性拱 | 通常 1/7 ~ 1/5 | 科普中国 / 百科「系杆拱桥」条目 |
| 圬工板拱、双曲拱 | 1/4 ~ 1/8（不宜小于 1/8） | 《桥梁工程》教材 A3-3.13 |
| 钢筋混凝土箱形拱 | 1/5 ~ 1/8（不宜小于 1/10） | 《桥梁工程》教材 A3-3.13 |
| 刚架拱、桁架拱 | 1/5 ~ 1/10（不宜小于 1/12） | 《桥梁工程》教材 A3-3.13 |

**补充（钢管混凝土中承式刚架系杆拱桥）**（《钢管混凝土拱桥设计施工与养护规范》7.1.3）：
- 边跨与中跨跨径之比宜为 **1/4.0 ~ 1/5.5**
- 边跨拱肋与中跨拱肋的矢高之比宜为 **1/3.5 ~ 1/4.5**
- 边跨拱肋矢跨比与中跨拱肋矢跨比之比宜为 **1/1.1 ~ 1/2.0**

> 术语约定：矢跨比 **小于 1/5 称坦拱，大于或等于 1/5 称陡拱**（《桥梁工程》A3-3.11）。

## 3. 拱肋截面与构造经验值

### 3.1 拱肋立面高度（钢管混凝土，估算式）

《钢管混凝土拱桥设计施工与养护规范》7.2.2，适用于跨径 ≤ 300 m、哑铃形或四肢桁式等高度截面：

```
H = k1 · k2 · [ 0.2·(l01/100)² + l01/100 + 1.2 ]      (m)
```

- `l01` — 拱肋净跨径（m）
- `k1` — 荷载系数：公路 I 级 / 城-A 取 **1.0**；公路 II 级 / 城-B 取 **0.9**
- `k2` — 行车道系数：2 或 3 车道取 **0.9**；4 车道取 **1.0**；6 车道取 **1.1**
- 四肢桁式拱肋宽度可取 **0.40H ~ 0.75H**
- 变高度截面：拱顶、拱脚可分别取计算值的 **80%** 与 **1.4 ~ 1.5 倍**

> 例：`l01 = 320 m`、公路 I 级 6 车道 → `H = 1.0×1.1×[0.2×3.2² + 3.2 + 1.2] = 1.1×6.448 ≈ 7.1 m`。
> 注：该式为**钢管混凝土**拱肋；钢箱拱肋（如菜园坝，立面高 4.0 m）明显更薄，不可套用。
> 脚本默认 `--arch_box_h = 拱净跨/80`（≥1.5 m），并允许显式覆盖。

### 3.2 其他构造经验值

| 项目 | 常用取值 | 备注 |
|---|---|---|
| 吊杆纵向间距 | **5 ~ 10 m** | 宜与桁梁节段长度、桥面板跨度对齐；菜园坝取 16 m（大节段公轨两用） |
| 拱肋内倾角（提篮拱） | **5° ~ 15°** | 菜园坝 10.67°；越大横向稳定性越好但施工越难 |
| 横撑道数 | 视跨径与横向稳定 | 菜园坝 6 道钢箱横撑 |
| 拱肋截面形式 | 钢箱 / 钢管混凝土（单圆管、哑铃形、桁式）/ 钢筋混凝土箱形 | 见规范 7.2.1 |
| 系杆布置 | 中跨、边跨**分开布置**时便于主动控制内力 | 无推力体系：水平推力由系杆平衡 |

**系杆拱组合体系三种基本分类**（按拱肋与系杆相对刚度，科普中国 / 百科「系杆拱桥」）：
柔性系杆刚性拱、刚性系杆柔性拱、刚性系杆刚性拱。拱轴线**通常采用二次抛物线**；
拱肋截面在肋高超过 1.5 ~ 3.5 m 时，采用工字形或箱形较为合理。

## 4. 实例参数表

### 重庆菜园坝长江大桥（脚本预设 `--preset caiyuanba`）

| 项目 | 参数 |
|---|---|
| 跨径布置 | 88 + 102 + **420** + 102 + 88 m（主桥 800 m） |
| 主拱净跨 | **320 m**（拱脚支承在 Y 型刚构前悬臂端，悬臂伸入主跨 50 m） |
| 矢高 / 矢跨比 | **56.44 m** / 1/5.67 |
| 拱轴线 | 二次抛物线 |
| 拱肋 | 封闭钢箱 2.4 × 4.0 m，内倾 **10.67°**（提篮式），6 道钢箱横撑 |
| 主梁 | 正交异性板钢桁梁，高 11.2 m，标准节段 16 m |
| 吊杆 | 间距 16 m |
| 桥面 | 上层双向六车道（净宽 30.5 m）+ 下层双线轻轨（轨道交通 3 号线） |
| 关键标高 | 桥面 232.00、拱脚 232.00（本技能口径）、拱顶 288.44、主墩墩顶 194.160 |
| 水位 | 枯水位 162.960 / 20 年一遇 189.330 / 100 年一遇 193.230 m |

> 实桥为**中承式**（拱脚在桥面以下、拱肋穿越桥面，拱顶高出枯水位约 115 m，
> 与公开记载"桥高 114 m"吻合）。脚本预设按用户确认的口径取「拱脚 = 桥面」；
> 若要还原实桥中承式几何，改 `--arch-foot-drop`（拱脚下沉量）与 `--main_pier_drop` 即可。

## 5. 脚本的坐标与绘图约定

便于后续修改 / 扩展脚本时对齐：

1. **相对标高基准**：桥面（上弦）= `0.000`，向上为正。水位等绝对标高经 `--deck_level` 换算。
2. **横竖向同比例**：比例 `S`（px/m）由 `S = min((width − 2·margin_x)/世界宽, (max_height − 固定高)/内容高)`
   决定，**不得**对 x / y 采用不同比例。
3. **绘制顺序**：主梁 → 水位河床 → 桥墩桩基 → Y 型刚构 → 主拱肋 → 吊杆 → 系杆 → 标注 → 说明条。
   拱肋后画，保证中承式穿越桥面时清晰可见。
4. **拱肋厚度**：按拱轴线**法向等厚偏移**（各点取切线法向 `±box_h/2`），
   而非简单的竖向偏移——后者在陡拱段会把拱肋画得比实际薄。
5. **吊杆截断**：仅绘制拱肋**下缘高于桥面 0.8 m 以上**的区段；中承式据此自动去掉桥面以下的吊杆。
6. **标注端点与构件坐标同源**：跨径标注端点一律取自 `PIER_X`（由 `spans` 累加得到），
   不得另写硬编码坐标，否则会出现"标注与桥墩错位"。
7. **中文标注重叠**：统一加 `paint-order="stroke" stroke="#ffffff" stroke-width="3.2"` 白描边（HALO）。
8. **Y 型刚构自动判定**：当拱净跨 < 主跨（拱脚内收）时自动生成刚构，前肢水平投影默认
   `(主跨 − 拱净跨)/2`；肢端延伸至桥面，若此时拱脚低于桥面则自动补下延锚固块。
9. **主墩墩顶标高**：有 Y 构时须低于拱脚 10 m 以上才能张开前后肢；无 Y 构时墩顶齐梁底。
