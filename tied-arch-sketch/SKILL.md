# 系杆拱桥立面草图生成

## 概述

本技能按桥梁设计参数生成**系杆拱桥**（下承式 / 中承式）的立面布置示意图，输出 SVG 矢量线条图。
以「桥面（上弦）= 0.000」为相对标高基准，横竖向**同比例**绘制，包含主拱肋、吊杆、系杆、
主梁（桁梁或系杆梁）、Y 型刚构、桥墩桩基、水位 / 河床线及各类尺寸标注。

适用场景：
- 方案设计阶段快速生成拱桥立面布置草图
- 校核拱净跨 / 矢高 / 矢跨比 / 吊杆间距是否合理
- 按既有设计立面图（CAD）参数重绘，或修正既有草图
- MIDAS Civil 建模前的参数核对参考

## 触发条件

出现以下情况时使用本技能：
- 用户要求绘制/生成**系杆拱桥**（含下承式、中承式、提篮拱、刚架系杆拱）草图或立面图
- 用户说"画个桥梁单线草图""桥梁单线示意图""单线简笔画"等（构件一线表示）
- 用户给出跨径、拱净跨、矢高、吊杆间距等参数并希望可视化
- 用户提到"拱桥草图""拱桥立面""系杆拱""提篮拱""拱肋布置图"等关键词
- 用户提供既有拱桥立面图（截图或 CAD）并要求按参数重绘 / 修正

> 注意区分：**斜拉桥**用 `bridge-sketch`，**平弦桁架桥**用 `steel-truss-sketch`，本技能只管**拱桥**。

## 工作流程

### 第一步：收集参数

从用户输入中提取参数。**必填**只有 `spans` 与 `output`，其余均有合理默认值。
完整参数表见下方「参数参考」。关键判断规则：

- 只给"跨径 420 米"这类单值 → 视为单跨，`--spans "420"`
- 给"88+102+420+102+88" → 直接作为跨径布置；中间最大跨自动识别为主跨
- 未给拱净跨 → 默认 = 主跨（拱脚落在主墩上，下承式）
- 未给矢高 → 默认 = 拱净跨 / 5（矢跨比 1/5）
- 拱脚不在主墩上、而是支承在刚构悬臂端 → 必须同时给 `--arch-span`（小于主跨）与 `--arch-foot-drop`
- 用户说"中承式""拱脚在桥面以下" → `--arch-foot-drop` 取正值（拱脚低于桥面）
- 用户说"下承式""拱脚在桥面" → `--arch-foot-drop 0`（默认）
- 用户说"提篮拱" → 用 `--arch-lean` 填内倾角（仅用于文字说明，立面图上体现不出内倾）
- 用户给了绝对标高（如"墩顶 194.16 m""枯水位 162.96 m"）→ 必须同时给 `--deck-level`（桥面绝对标高）

**标注开关（重要）**：默认只画跨径、拱净跨、梁高标注。
`--show-rise-dim`（矢高）与 `--show-elev-marks`（标高倒三角符号）**默认关闭**，用户明确要求时才打开；
用户说"删除矢高/标高标注"时，不传这两个开关即可（它们本来就是关的；若之前打开过则去掉）。

### 第二步：运行脚本

用受管 Python 环境运行：

```bash
"C:/Users/Administrator/.workbuddy/binaries/python/versions/3.13.12/python.exe" \
  "C:/Users/Administrator/.workbuddy/skills/tied-arch-sketch/scripts/generate_tied_arch_sketch.py" \
  --spans "88+102+420+102+88" --arch-span 320 --rise 56.44 \
  --hanger-spacing 16 --output <输出路径.svg>
```

参数多时可用 JSON 传参（键名与长参数一致，用下划线）：

```bash
... generate_tied_arch_sketch.py \
  --json-str '{"spans":"76+360+76","arch_span":360,"rise":72,"axis":"parabola"}' \
  --output out.svg
```

参数优先级：**默认值 < `--preset` < `--json-str` < 显式命令行参数**。

已有预设：`--preset caiyuanba`（重庆菜园坝长江大桥，中承式提篮钢箱系杆拱 + Y 型刚构 + 公轨两用桁梁）。

### 第三步：检查输出

脚本向 stdout 打印参数汇总（跨径、拱净跨、矢高、矢跨比、吊杆根数、拱顶 / 拱脚相对标高、水位、河床）
与合理性提示。**必须核对**：

- 吊杆根数 × 吊杆间距 是否与拱净跨匹配（首末吊杆不应贴到拱脚）
- 拱顶标高（相对桥面）是否为正且明显高于桥面
- 拱肋立面高度是否过厚（超过矢高 2/3 会显得臃肿）
- 中承式（`arch_foot_drop > 0`）时，拱肋是否确实穿过桥面、吊杆是否只出现在桥面以上

如需视觉自检，用 Edge 无头截图（零依赖）：

```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless --disable-gpu \
  --screenshot="<预览.png>" --window-size=1830,530 --default-background-color=FFFFFFFF \
  "file:///<输出.svg>"
```

### 第四步：呈现与归档

1. 用 `present_files` 展示 SVG
2. 回复中附参数汇总表（跨径、拱净跨、矢高、矢跨比、吊杆数、关键标高）
3. 按用户习惯归档：桥梁草图 → 桥梁知识库 `06 草图/`；参数条目 → `02拱桥/`（.md，带 frontmatter）

## 参数参考

### 桥名与文字

| 参数 | 说明 | 默认 |
|---|---|---|
| `--name` | 桥梁名称（用于说明条首行与标题） | 空 |
| `--bridge_type` | 桥型描述（副标题与说明条） | 空 |
| `--title` | 图名，留空则自动生成 | 自动 |
| `--subtitle` | 副标题，留空则自动为「跨径 ｜ 桥型」 | 自动 |
| `--deck_notes` | 桥面构造注记，分号分隔，各带引出线（如"上层：…;下层：…"） | 空 |
| `--info_lines` | 底部说明条全文覆盖，分号分隔（首行加粗） | 自动生成 |
| `--preset` | 预设：`caiyuanba` / `simply-supported` | 空 |

### 跨径布置

| 参数 | 说明 | 默认 |
|---|---|---|
| `--spans` | **必填**，如 `"88+102+420+102+88"` | — |
| `--ext_left` / `--ext_right` | 两端引桥延伸长度（m） | 0 |
| `--approach_pier` / `--no-approach_pier` | 是否画引桥墩 | 画 |

### 主拱

| 参数 | 说明 | 默认 |
|---|---|---|
| `--arch_span` | 拱计算（净）跨径（m） | = 主跨 |
| `--rise` | 矢高（m） | = 拱净跨/5 |
| `--axis` | 拱轴线：`parabola` / `catenary` / `circle` / `power` | parabola |
| `--axis_n` | `power` 模式的指数（2 = 二次抛物线） | 2.0 |
| `--cosh_m` | 悬链线拱轴系数 m | 1.167 |
| `--arch_offset` | 拱跨中心相对主跨中心的偏移（m，正=向右） | 0 |
| `--arch_foot_drop` | 拱脚低于桥面的高差（m）。0 = 下承式；>0 = 中承式 | 0 |
| `--arch_box_h` | 拱肋立面高度（m） | 拱净跨/80（≥1.5） |
| `--arch_box_w` | 拱肋横断宽度（m，仅文字） | 0.6×box_h |
| `--arch_material` | 拱肋材料（仅文字） | 钢箱 |
| `--arch_lean` | 拱肋内倾角（°，提篮拱，仅文字） | 0 |
| `--n_brace` | 横撑道数（仅文字） | 0 |

### 主梁 / 桥面

| 参数 | 说明 | 默认 |
|---|---|---|
| `--deck_depth` | 主梁高度（桁梁高 / 系杆梁高，m） | 2.0 |
| `--girder` | `truss`（桁梁，带腹杆格构）/ `box`（系杆梁，箱形双线） | box |
| `--segment` | 节段长度（m），桁架腹杆间距 | = 吊杆间距 |
| `--dual_deck` / `--no-dual_deck` | 是否画公路面线 + 轨道面虚线 | 关 |

### 吊杆与系杆

| 参数 | 说明 | 默认 |
|---|---|---|
| `--hanger_spacing` | 吊杆纵向间距（m） | 8.0 |
| `--hanger_start` | 首根吊杆距拱脚的距离（m） | = 吊杆间距 |
| `--tie_offset` | 系杆低于拱脚 / 下弦的高差（m） | 2.5 |
| `--side_tie` | 是否画边跨系杆：`auto` / `yes` / `no` | auto（有 Y 构时画） |

### 桥墩与刚构

| 参数 | 说明 | 默认 |
|---|---|---|
| `--y_frame` | Y 型刚构：`auto` / `main` / `none` | auto（拱净跨 < 主跨时自动加） |
| `--y_front` | 前肢水平投影（m） | (主跨 − 拱净跨)/2 |
| `--y_back` | 后肢水平投影（m） | 0.8 × 前肢 |
| `--y_to_deck` / `--no-y_to_deck` | 前、后肢上端是否延伸至桥面 | 延伸 |
| `--main_pier_drop` | 桥面至主墩墩顶的高差（m） | 有 Y 构时自动；无 Y 构时墩顶齐梁底 |
| `--pier_w_main` / `--pier_wt_main` | 主墩底 / 顶宽（m） | 14 / 12 |
| `--pier_w` / `--pier_wt` | 其他墩底 / 顶宽（m） | 8 / 6 |

### 水位 / 高程

| 参数 | 说明 | 默认 |
|---|---|---|
| `--deck_level` | **桥面绝对标高（m）**。给水位的绝对标高时**必须**给出 | 0 |
| `--water` | 水位，格式 `"名称=标高;名称=标高"`。名称含"枯"时画波浪实线，其余画虚线 | 空 |
| `--bed_level` | 河床绝对标高（m） | = 最低水位下 14 m |
| `--bed_below_water` | 无 `--bed_level` 时，河床低于最低水位的深度（m） | 14 |
| `--ground_depth` | 完全无水位参数时，地面低于桥面的深度（m） | 30 |
| `--river_note` / `--river_note_pos` | 河槽文字及其水平位置（占全宽比例） | 空 / 0.42 |
| `--bed_note` / `--bed_note_pos` | 河床 / 岸线文字及位置 | 空 / 0.85 |

**标高约定**：水位值默认按**绝对标高**解释，并以 `--deck_level` 换算为相对桥面的高差。
若不传 `--deck_level`（保持 0），则水位值即"相对桥面的高差"，水面应写负值。

### 标注开关

| 参数 | 说明 | 默认 |
|---|---|---|
| `--show_span_dims` / `--no-show_span_dims` | 跨径分跨 + 主桥全长标注 | **开** |
| `--show_arch_span_dim` | 拱净跨标注 | **开** |
| `--arch_span_dim_offset` | 拱净跨标注线低于拱脚的高差（m） | 1.5 |
| `--show_rise_dim` | **矢高标注** | **关** |
| `--show_elev_marks` | **标高倒三角符号**（拱顶 / 桥面 / 主墩墩顶） | **关** |
| `--show_water_labels` | 水位名称 + 高程文字 | **开** |
| `--show_girder_depth_dim` | 桁高 / 梁高标注 | **开** |
| `--show_pier_labels` | 桥墩名称标注（主墩 / 边墩 / 过渡墩 / 引桥墩） | **开** |
| `--show_leaders` | 桥面构造引出标注（需 `--deck_notes`） | **开** |
| `--show_info_box` | 底部参数说明条 | **开** |

### 画布

| 参数 | 说明 | 默认 |
|---|---|---|
| `--width` | 画布宽度上限（px） | 1830 |
| `--max_height` | 画布高度上限（px），短跨桥自动缩尺 | 660 |
| `--margin_x` | 左右页边（px） | 24 |
| `--scale` | 显式指定比例（px/m），一般留空自动 | 自动 |
| `--output` / `-o` | **必填**，输出 SVG 路径 | — |

## 草图包含内容

- **主拱肋**：按拱轴线**法向等厚偏移**绘制（陡拱段不会显薄），拱脚带锚固圆圈
- **吊杆**：自拱肋下缘竖直到桥面，仅出现在桥面以上（中承式自动截断）
- **系杆**：中跨系杆（红色点划）在拱脚标高处；边跨系杆在梁底以下（有 Y 构时）
- **主梁**：桁梁（上下弦 + 竖杆 + 交替斜腹杆格构）或系杆梁（箱形双线 + 节段虚线）
- **Y 型刚构**：自墩顶向上张开前、后肢，肢端延伸至桥面；拱脚低于桥面时自动补下延锚固块
- **桥墩**：主墩 / 边墩 / 端部过渡墩 / 引桥墩，带承台与桩基
- **水位与河床**：多条水位线（不同线型）+ 虚线河床 + 名称高程
- **尺寸标注**：跨径、拱净跨、梁高，以及可选的矢高与标高符号
- **参数说明条**：底部横排，自动汇总跨径 / 拱肋 / 梁 / 吊杆 / 标高

## 已知限制

1. **立面图不表达横断面**：提篮拱内倾角、横撑、拱肋断面宽度只在说明条里以文字体现
2. **拱肋高度不自动变高**：实桥常按内力变高（拱脚高、拱顶矮），本技能按等截面绘制
3. **标注重叠**：拱脚位于桥面时，"拱净跨"标注线必然落在梁体内与腹杆交叉；可用
   `--arch_span_dim_offset` 调大偏移量把它移到梁下
4. **吊杆为竖直布置**：未实现斜吊杆（网拱）形式

## 示例

**示例 1：菜园坝长江大桥（一键预设）**
```
用户：画一下菜园坝长江大桥的立面示意图
→ --preset caiyuanba -o 菜园坝长江大桥_420m.svg
→ 88+102+420+102+88 m；拱净跨 320 m、矢高 56.44 m、矢跨比 1/5.67；拱脚在桥面；
   Y 构前肢 50 m / 后肢 40 m；桁梁 11.2 m；19 根吊杆 @ 16 m；三条水位线
```

**示例 2：下承式简支系杆拱**
```
用户：画一个下承式系杆拱桥，跨径 100 米，矢跨比 1/5，吊杆间距 5 米
→ --spans "100" --rise 20 --hanger-spacing 5 --girder box --y-frame none --ground-depth 25
→ 单跨 100 m、矢高 20 m、19 根吊杆、箱形系杆梁
```

**示例 3：中承式刚架系杆拱（拱脚在桥面以下）**
```
用户：中承式系杆拱，跨径 76+360+76，拱净跨 360，矢高 72，拱脚在桥面以下 8 米
→ --spans "76+360+76" --arch-span 360 --rise 72 --arch-foot-drop 8 --hanger-spacing 8
→ 拱净跨 = 主跨时 Y 构自动省略；若拱净跨 < 主跨则自动生成 Y 型刚构并设拱脚锚固块
```

**示例 4：按绝对标高绘制**
```
用户：桥面标高 232.00，枯水位 162.96，100 年一遇洪水位 193.23
→ --deck-level 232.0 --water "100 年一遇洪水位=193.230;枯水位=162.960"
→ 水位自动换算为相对桥面高差（−38.77 / −69.04），图中标注仍显示绝对标高
```

**示例 5：只要素图（去掉矢高与标高标注）**
```
用户：把矢高和标高标注去掉，只要跨径和拱净跨
→ 默认即满足（show_rise_dim / show_elev_marks 默认关闭）
→ 如需进一步精简：--no-show-girder-depth-dim --no-show-pier-labels --no-show-info-box
```
