# 连续刚构箱梁构造尺寸速查

输入主跨跨径，输出该跨径下的**推荐构造尺寸**与**技术指标经验值**，并列出同跨径实桥对照。

> 在线版：<https://huigeshuo.github.io/bridge-skills/>

## 它解决什么问题

方案阶段定连续刚构的梁高、底宽、悬臂长度时，通常要翻好几份已完工程图纸找参照。
这个工具把 34 座连续刚构桥的实测构造尺寸汇总成一个库，输入主跨就能得到：

- **推荐根部梁高 / 跨中梁高** —— 取全库梁高跨比中位值 × 输入跨径，取整到 5 cm
- **常用区间** —— 同跨径区间的 P10 ~ P90，用来看推荐值是否偏保守
- **技术指标参考** —— 砼含量 m³/m²、钢束含量 kg/m² 与 kg/m³
- **同跨径实桥对照** —— 按 |Δ主跨| 排序取最接近的 8 座，直接比对梁高与配束
- **梁高—主跨趋势图** —— 散点 + 经验带，标出当前输入跨径的位置

## 文件说明

| 文件 | 作用 |
|---|---|
| `extract.py` | 从 Excel 原始表提取数据，产出 `data.json` |
| `build.py` | 把 `data.json` 注入 `template.html`，生成单文件 `index.html` |
| `template.html` | 页面模板（HTML + CSS + JS 一体，`/*__DATA__*/` 为数据占位符） |
| `make_public.py` | 按映射表把桥名替换为拼音首字母代号，产出对外脱敏版 |
| `example_data.json` | **已脱敏的完整数据**（34 条，桥名代号化），可直接用于重建页面 |

## 怎么用

```bash
# 1. 用示例数据直接重建页面（不需要任何额外数据）
cp example_data.json data.json
python build.py          # 产出 index.html，双击即可用

# 2. 换成自己的数据
#    把 data.json 换成 extract.py 从你的 Excel 里提取的结果，再跑 build.py

# 3. 生成对外脱敏版
python make_public.py    # 按 code_map 替换桥名，输出到 publish/
```

`data.json` 已在 `.gitignore` 中排除——**真实工程数据不进仓库**，
仓库里只保留 `example_data.json` 这份代号化数据。

## 数据口径

- 主跨、桥宽单位 **m**；梁高、板厚、悬臂长度、底宽单位 **cm**
- 砼含量 = 砼方量 m³ ÷ 桥梁面积 m²
- 钢束含量 = 钢束重量 kg ÷ 桥梁面积 m²，另附 kg ÷ 砼方量 m³
- 桥名以拼音首字母代号表示（如 `LKDQ`），幅别保留中文，同名加序号区分
- 尺寸与工程量均为原表实测记录，未作修改
