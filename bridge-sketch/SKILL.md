# 斜拉桥立面草图生成

## 概述

本技能根据桥梁设计参数（跨径布置、塔上拉索间距、梁上拉索间距等），
自动生成斜拉桥立面布置草图。输出为 SVG 矢量图，以线条绘制，
包含桥面、索塔、拉索、桥墩、桥台及尺寸标注。

适用场景：
- 桥梁方案设计阶段快速生成立面布置草图
- 验证拉索布置方案是否合理（索数、间距、覆盖范围）
- 向他人展示斜拉桥总体布置方案
- 作为 MIDAS Civil 建模前的参数校验参考

## 触发条件

当出现以下情况时使用此技能：
- 用户要求绘制/生成斜拉桥草图、立面图
- 用户提供了跨径、索距等参数并希望可视化
- 用户提到"桥梁草图""斜拉桥立面""拉索布置图"等关键词
- 用户描述了桥梁参数并要求"画一下""画个草图""出个图"

## 工作流程

### 第一步：收集参数

从用户输入中提取以下参数（带 * 为必填）：

| 主跨位置 | `main_side` | 独塔时主跨位置：`left`=主跨在左/边跨在右，`right`=主跨在右/边跨在左 | left |
| 主跨跨径* | `main_span` | 主孔跨长 (m) | 300 |
| 边跨跨径 | `side_span` | 左右边跨 (m)，对称时使用 | 120 |

| 右边跨跨径 | `side_span_right` | 右边孔跨长 (m)，非对称时使用 | =side_span |

| 塔上索距下限 | `d_tower_min` | 渐变时底部(最小)索距 (m)，与 d_tower_max 配合 | =d_tower |
| 塔上索距上限 | `d_tower_max` | 渐变时顶部(最大)索距 (m) | =d_tower |

| 主跨梁上索距 | `d_deck_main` | 主跨侧梁上索距 (m)，与边跨不同时使用 | =d_deck |
| 边跨梁上索距 | `d_deck_side` | 边跨侧梁上索距 (m) | =d_deck |
| 边跨近塔段索距 | `d_deck_side_near` | 边跨近塔段梁上索距 (m)，变距时使用 | =d_deck_side |

| 主跨梁上索距模式 | `deck_main_pattern` | 索距分段表达式，如 `"16+25*8+16"` | 无 |
| 边跨梁上索距模式 | `deck_side_pattern` | 索距分段表达式，如 `"15+11*5+14*4+4"` | 无 |
| 主跨索数 | `n_main` | 主跨侧拉索数量，覆盖自动计算 | 自动 |
| 边跨索数(独塔右侧) | `n_side_right` | 边跨侧拉索数量，覆盖自动计算 | 自动 |
| 辅助墩位置 | `aux_piers` | 辅助墩绝对x坐标列表，如 `[302,342]` | 无 |
| 边跨分段跨径 | `aux_pier_spans` | 独塔模式边跨分段（从塔向外），如 `[70,40,20]`，自动换算墩位 | 无 |
| 辅助墩宽度 | `aux_pier_width` | 辅助墩显示宽度 (m) | 2.5 |
| 索塔高度 | `tower_height` | 塔顶至桥面高度 (m)，不指定则自动计算 | 自动 |
| 桥墩高度 | `pier_height` | 桥面至地面高度 (m) | 12.0 |
| 塔身宽度 | `tower_width` | 索塔截面宽度 (m)，仅影响显示 | 3.0 |
| 取消塔高标注 | `show_tower_h_dim` | `false` 时不画塔高"H=..."标注 | true |

| 主梁形式 | `deck_mode` | `line`=单线粗线 / `truss`=桁梁(上下弦+竖杆+斜腹杆) | line |
| 桁架节间 | `truss_panels` | 桁梁节间长度 (m) | 8.0 |

| 基础底深 | `pier_base_depth` | 塔/墩基础底面深度 (桥面以下 m)，留空则落在河床上 | 自动 |
| 承台桩基 | `pier_cap` | 是否画承台+桩基（河流模式） | true |

**关键判断规则：**
- 若用户只说了一个"跨径"值 → 视为主跨，边跨取主跨的 0.4~0.5 倍
- 若用户说了"跨径 430+180" → 主跨430，边跨180
- 若用户说了"塔上索距"和"梁上索距" → 分别对应 d_tower 和 d_deck
- 若用户未指定塔高 → 脚本自动计算：(最大索对数+1) × 最大塔上索距
- 若用户提到"独塔""单塔"或描述真实独塔桥（如月湖桥）→ 加 `--single-tower`
- 独塔时判断主跨方向：跨径写成"主跨+边跨"（如 `232+70+40+20`）→ 主跨在左，默认 `--main-side left`；跨径写成"边跨分段+主跨"（如 `(28.6+34+75.4)+232`）→ 主跨在右，加 `--main-side right`，且 `--aux-pier-spans` 从塔向外分段（`75.4,34,28.6`）
- 若用户提到塔上索距是"1.3~2.5"这类范围 → 用 `--d-tower-min 1.3 --d-tower-max 2.5` 实现渐变
- 若边跨索距是变距（如"近塔段8m×8对，其余3.4m"）→ 用 `--d-deck-side-near 8 --d-deck-side-near-count 8 --d-deck-side 3.4`
- 若用户给出总跨径布置如"(232+70+40+20)m"且边跨有辅助墩 → 用 `--aux-pier-spans "70,40,20"`（独塔，从塔向边跨分段），脚本自动把辅助墩放在 70、110m 处；也可直接用 `--aux-piers "302,342"` 指定绝对x坐标
- 若用户用工程表达式描述梁上索距（如"主跨索距(16+25*8+16)m""边跨索距(15+11*5+14*4+4)m"）→ 用 `--deck-main-pattern "16+25*8+16"` 和 `--deck-side-pattern "15+11*5+14*4+4"`，脚本自动解析分段间距和索数，无需手动算 n_main/n_side_right
- 若用户要求"取消塔高/索距标注""去掉尺寸标注"→ 加 `--no-tower-h-dim`（去掉塔高标注）、`--no-spacing-dims`（去掉塔上/梁上索距标注），跨径标注保留
- 若用户提到**稀索体系 / 部分斜拉桥 / 大范围无索区**（如实桥"塔处无索区109m、跨中无索区80m"）
  → 用 `deck_main_pattern` / `deck_side_pattern` 把**塔根到首索的空白**写进 offset，把**末索到跨端的空白**写进末尾标量。
  例：`"54.5+8*16+40"` = 塔根 54.5 m 起、8 个 16 m 间距（共 9 根索）、末索距跨端 40 m
- 若给出**两岸锚固端距离**或"最内/最外索距塔距离" → 直接换算成 offset / end_gap 填进索距模式
- 若用户要求"按图复刻""立面布置图" → 建议加 `--dims-top`（跨径标注置于塔顶以上）与 `--end-labels`（两岸地名）
- 若桥跨河流 → 加 `--river --water-depth <水面深> --bed-profile "x:d,..." --pier-base-depth <基础底深>`

### 第三步：检查输出

脚本运行后会输出：
1. **参数汇总**（stdout）：包含跨径、塔高、索数等计算结果和校验警告
2. **SVG文件**：保存在 `--output` 指定路径

**必须检查的校验项：**
- 双塔时：索数 × 梁上索距 是否超过主跨/2（主跨侧）或边跨长度（边跨侧）→ 拉索可能重叠
- 独塔时：主跨索数 × 索距 是否超过主跨全长；边跨同理
- 索对数 × 塔上索距 是否超过塔高 → 锚点可能超出塔顶
- **索根数反算**：每索面根数 = Σ(各区段长度 ÷ 该段梁上索距)，必须与图纸/资料给出的总索数吻合
- **锚点对应关系**：最长索在塔顶 ⟷ 梁上最远；最短索在塔底 ⟷ 梁上最近（两者正相关，写反会使索交叉成 X 形）

如有警告，向用户说明并建议调整参数。详见 `references/cable_stayed_bridge_geometry.md` 第 6 节"出图自检"。

## 草图包含内容

生成的SVG立面草图包含以下元素：
- **桥面（主梁）**：水平粗线（`deck_mode=line`），或**桁梁**（上下弦 + 竖杆 + 交替斜腹杆，`deck_mode=truss` + `truss_panels` 节间）
- **索塔**：竖向粗线，位于边跨与主跨交界处
- **拉索**：细线，从塔上锚点连接到梁上锚点（半扇形布置；支持**稀索 + 无索区**的 offset/end_gap 精确控制）
- **桥墩**：索塔下方的矩形，连接塔底与地面（或河床）；河流模式下带**承台 + 桩基**
- **辅助墩**：边跨内的桥墩（支持 `aux_piers` / `aux_pier_spans` 指定位置）
- **桥台**：桥梁两端的支承结构
- **地面线**：虚线 + 剖面线；开启 `river` 后改为**水面线（点划线）+ 河床曲线**
- **尺寸标注**：跨径、塔高、索距（蓝色箭头标注；`show_tower_h_dim`/`show_spacing_dims` 可关掉塔高和索距部分；`dims_top` 把跨径标注移到塔顶以上）
- **两端地名标注**：`end_labels`，箭头朝外
- **索数标注**：每塔主跨/边跨侧拉索数量
- **参数信息框**：右上角汇总关键参数，可用 `notes` 追加文字

## 拉索布置规则

脚本采用**半扇形（semi-fan）**布置方式：
1. 最长索（离塔最远）锚于塔顶附近
2. 最短索（离塔最近）锚于塔底附近
3. 塔上锚点间距 = d_tower（可渐变：顶部 d_tower_max → 底部 d_tower_min）
4. 梁上锚点间距 = d_deck（主跨/边跨可不同，边跨可近塔段变距）
5. 主跨侧索与边跨侧索在同一高度配对
6. 双塔时：主跨索数 = floor(主跨/2 / 梁上索距)
7. 独塔时：主跨索数 = floor(主跨 / 梁上索距)
8. 边跨索数 = floor(边跨 / 梁上索距)，支持近塔段 `d_deck_side_near × d_deck_side_near_count` + 远端 `d_deck_side`
9. 提供 `n_main`、`n_side_right` 可直接指定索数，覆盖自动计算（用于精确匹配图纸）

## 拉索绘制硬性自检（手绘/手写 SVG 时同样适用）

> 2026-10-27 用户指出嘉鱼长江大桥立面图"斜拉索画的有问题"，两条硬规则自此强制执行。

**① 索根数由索距反算，不得凭观感取数。**
先算 `Σ(区段长度 ÷ 该段梁上索距)`，与资料给出的总索数对账，再动笔。
嘉鱼桥实例：北边跨 300/9=32 + 主跨每侧 460/15=30 + 南边跨 430/15=28
= **每索面 120 根 → 全桥 240 根**。首版图误画成每索面 47 根，主跨侧索距
被画成 33.5 m（标称 15 m），失真 3 倍。**索距是桥梁工程师看这张图的第一眼
信息，任何情况下都不能为"图面清爽"而改索距。**

**② 塔上锚点与梁上锚点"高对远、低对近"。**
最长索锚在塔顶附近、梁上最远点；最短索锚在塔底附近、梁上最近点。
写成"塔上越低、梁上越远"会让索在塔身处交叉成倒扇形（X 形），几何上不成立。
自检方法：从塔向跨中逐根看，索的倾角应单调变缓（斜率绝对值递减）。

**③ 遮挡与无索区。**
索起点画在塔柱中心线，索塔 rect 必须比索**后**绘制（后画者在上层），
使索从塔侧露出而非穿塔而过；跨中、梁端保留无索区（合龙段一般 10~20 m），
两侧最内索不得在跨中相接。

### 索距模式（deck_main_pattern / deck_side_pattern）

当索距分段变化时，可用工程表达式直接描述，格式为：

```
offset + n1*s1 + n2*s2 + ... + end_gap
```

- `offset`：塔根到第一根索的距离
- `n_i*s_i`：第 i 段，n_i 个间距，每个 s_i 米（相邻段共用边界锚点）
- `end_gap`：最末索到跨端的距离

**示例：**
- `"16+25*8+16"` → 26 根索，距塔 [16, 24, 32, ..., 216]m（首索16m，末索216m，末端16m）
- `"15+11*5+14*4+4"` → 26 根索，距塔 [15, 20, ..., 70, 74, ..., 126]m（近塔段11个5m间距+远段14个4m间距）

提供模式后，脚本自动计算索数和锚点位置，无需再传 `d_deck_main`、`n_main` 等参数。
