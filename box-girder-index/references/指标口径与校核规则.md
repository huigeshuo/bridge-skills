# 指标口径与校核规则

> 本文件解释「为什么这么算」「为什么这么判」，改阈值的依据都在这里。

## 一、三个指标的分母为什么不能混用

| 指标 | 分母 | 用途 |
|---|---|---|
| 砼含量 m³/m² | 桥梁面积（桥面投影） | 方案阶段估砼方量：面积 × 含量 |
| 钢绞线 kg/m² | 桥梁面积 | 估预应力材料总量，与桥面规模挂钩 |
| 钢绞线 kg/m³ | 砼方量 | **配束强度指标**，反映"每方砼里塞了多少钢绞线" |

- `kg/m²` 适合**估算**（面积最好拿，方案阶段就有）；
- `kg/m³` 适合**评判设计合理性**（同等砼量下预应力水平），与跨径、梁高强相关；
- 两个指标不能互相替代：宽桥 kg/m² 会被摊薄而 kg/m³ 不变；分叉联面积分母小，
  kg/m² 会虚高。

## 二、桥梁面积取值

1. 优先取源表"桥梁面积(m2)"列（设计院已算好，已考虑变宽渐变）；
2. 源表无此列时才反算：`联长 × (起点宽 + 终点宽) / 2`，并把 `flags` 标为推算；
3. 校验：反算值 vs 源表值偏差 >3% 即报警——通常是宽度或联长有一个抄错。

本库案例中 45 联全部满足 `面积 = 联长 × 平均宽`（误差 <0.1%），说明源表面积列
就是按此口径算的，可放心用。

## 三、跨径文本解析规则

| 写法 | 解析结果 | 说明 |
|---|---|---|
| `24.732+3*30.005` | 24.732, 30.005×3 | 和 = 114.747，等于联长 |
| `3*33.5` | 33.5×3 | 等跨联 |
| `分叉2*23.25` | 23.25×2 | "分叉"只是标记，不影响数值 |
| `25分叉` / `26.363分叉` | 25 / 26.363 | 前后缀均可 |
| `36.5` | 36.5 | 单跨 |

- `n×L` 里的 **n 是跨数、L 是单跨长**，不是 n×L 相乘；
- 跨径和与联长不符时优先怀疑：漏写一跨、多写一跨、"3*"的 3 写成了跨长。
  案例：`26.363分叉` 而联长 23.363，差 3.0m，属源表笔误。

## 四、校核阈值来由

| 参数 | 值 | 依据 |
|---|---|---|
| `TOL_LEN` | 2% 且 ≥0.05m | 跨径文本常有 0.001m 级取整差，2% 可容错但不放过整跨漏写 |
| `TOL_AREA` | 3% | 变宽联的渐变面积与梯形公式有微小差异，3% 内属正常 |
| `WIDTH_RATIO` | 2.0 | 变宽联、匝道分流段宽度比可到 2 左右；超过 2 且非分叉联，八成是小数点错位 |
| `conc_ratio` | 0.45~1.30 | 常规现浇预应力砼箱梁 0.6~1.0；分叉/加宽段到 1.15；低于 0.45 基本是砼漏填，高于 1.3 基本是砼多填或面积少填 |
| `strand_m2` | 6~75 | 常规 15~45；分叉段因面积小而偏高；<6 多为漏填 |
| `strand_m3` | 10~75 | 常规 20~40；分叉段砼集中可低至 12 |
| `plate_m2` | 100~800 | 钢箱梁（含砼桥面板）常见 400~800，纯钢箱 100~300 |

阈值都集中在脚本顶部常量区，项目习惯不同可直接改，但**改完要在 SKILL.md 案例里注明**，
否则下次统计口径会漂移。

## 五、钢箱梁块的"砼数量"陷阱

汇总表里钢箱梁区块常直接复用砼箱梁的表头，`砼数量(m3)` 列实际填的是**钢板 kg**：

| 案例行 | 表头 | 实际值 | 判定 |
|---|---|---|---|
| 滠口高架 5 联 | 砼数量(m3) | 4 692 617.3 | ÷6319m² = 742 → 只能是 kg 钢板 |

识别规则：`值 / 面积 > 5` 即判为钢板（砼含量物理上不可能超过 5 m³/m²），
自动转列并置 `struct_type = 钢箱梁`。**钢箱梁块钢绞线为 0 不算错误**（纯钢梁无预应力），
只有砼箱梁才报"钢绞线为0"。

## 六、统计口径

- 只用 `flags` 为空的记录；
- 给 **P25 / 中位值 / P75** 而不是平均值——含量数据有长尾（分叉联、特殊联），
  中位数更稳；平均值仅作参考列；
- 按 `max_span` 分档：≤20m、20~30m、30~40m、≥40m，档内取中位值；
- 样本数 <5 的档位只作参考，回答时要说明。

## 七、常见坑

1. **桥名是纵向合并单元格** → openpyxl 只在首行有值，必须按合并区填充，否则后几联桥名丢失；
2. **表头含字间空格/全角括号**（"砼 数 量（m3）"）→ 匹配前统一去空白、括号转半角；
3. **同名文件多版本**（`-szh`、`-胡晓莉`、`-青峰`）→ 用 `--project` 显式给工程名，
   别让文件名成为工程名，否则统计分组会碎；
4. **`.xls` 老格式** → 需要 `xlrd`；xlrd 拿不到合并信息，桥名列若为空要换 .xlsx；
5. **重跑会覆盖同位置记录**（这是有意设计），但不同文件同位置不会互相干扰；
6. **备注列以 `=` 开头**会被当成公式，写 CSV/MD 前已按纯文本处理，不必担心。
