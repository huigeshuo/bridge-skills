# 箱梁技术指标库（Excel → 指标库）

把设计院口径的「钢束含量汇总表」自动拆成一条条可比对的指标记录，
累积成一个**跨项目**的材料指标库，用于方案阶段快速判断"这个跨径、这个宽度，
砼和钢绞线大概该是多少"。

## 零、最快怎么用（推荐）

**不用记命令，直接说人话就行**，把 Excel 拖进对话 + 一句话：

| 你说 | 我干的事 |
|---|---|
| "把这份钢束含量表提出来建指标库 @表.xlsx" | 跑脚本 → 生成 JSON/CSV/MD/HTML + 归档知识库 |
| "再并一份青峰的表进来" | 追加合并，自动去重 |
| "30m 现浇箱梁砼含量一般多少" | 直接查已有库，给区间+中位值+样本数 |
| "我这个联 0.95 m³/m² 正常吗" | 算完和同跨径档位中位值比，给偏离百分比 |
| "帮我看看这份表有没有填错的" | 校核体检，列出待核行和源行号 |

显式调用也可以：对话里发 `/box-girder-index 提取这份表`，或直接让我跑下面的命令。

## 一、什么时候用

- 用户发来一个/多个 Excel（钢束含量汇总表、桥梁技术指标表），要求提取指标；
- 用户问"30m 现浇箱梁砼含量一般多少""某项目钢绞线 kg/m³ 是否偏高"；
- 要新建项目的主梁指标，需要同类型桥梁的经验区间做对比；
- 汇总表数据疑似有错（含量异常、面积对不上），需要体检。

## 二、指标口径（唯一真相）

| 指标 | 字段 | 公式 | 单位 |
|---|---|---|---|
| 砼含量 | `conc_ratio` | 砼方量 ÷ 桥梁面积 | m³/m² |
| 钢绞线含量（面积） | `strand_m2` | 钢绞线重量 ÷ 桥梁面积 | kg/m² |
| 钢绞线含量（体积） | `strand_m3` | 钢绞线重量 ÷ 砼方量 | kg/m³ |
| 钢板含量 | `plate_m2` | 钢板重量 ÷ 桥梁面积 | kg/m²（钢箱梁） |
| 延米砼 | `conc_per_m` | 砼方量 ÷ 联长 | m³/m |
| 延米钢绞线 | `strand_per_m` | 钢绞线重量 ÷ 联长 | kg/m |

- **桥梁面积**取表内"桥梁面积(m2)"列；若源表缺失，用 `联长 × (起点宽+终点宽)/2` 反算，
  并在 `flags` 注明是推算值。
- 变宽联（分叉、加宽段）一律用平均宽度；分叉联砼含量天然偏高（可达 1.1~1.2 m³/m²），
  不可与等宽联直接比。
- 钢箱梁块的"砼数量"列常是表头复制残留、实际填的是钢板 kg，
  脚本按 `值/面积 > 5` 自动识别并转成 `plate_m2`，同时把 `struct_type` 置为"钢箱梁"。

## 四、能自动识别的表格形态

- **一个 sheet 多个区块**：靠横向合并 ≥4 列的标题行切分（"××互通(现浇）"/"(钢箱梁）"），
  按标题文字判 `struct_type`；
- **桥名纵向合并**：合并区左上角的值自动向下填充到本联所有行；
- **跨径自由文本**：`24.732+3*30.005`、`3*33.5`、`分叉2*23.25`、`30分叉`、`36.5`
  → 解析成 `spans` 数组，同时给 `n_spans`、`max_span`、`span_sum`；
- **表头位置不固定**：任一表行命中 ≥3 个表头关键字即认作表头，支持多级表头；
- **列序可变**：按关键字匹配列，不按固定列号；
- **两种宽度写法**：`起点宽度/终点宽度` 两列（汉口北表）或单列 `宽度`（青峰、涂店表），
  单列时起终点取同值，面积校验照常进行；
- **互通/匝道列**：表头有 `匝道`/`互通`/`工区` 列时自动识别为 `route` 维度（纵向合并同样填充）；
  没有这类列时用 `--route "互通名"` 指定。不同互通常有重名桥（如 `C1-2` 同时存在于小菜湖、
  喻家咀），**必须靠 route 区分**，否则分组统计会串；
- **占位行**：砼与钢绞线都空的行（只有桥名/跨径/面积）自动跳过并报数，不入库；
- **老 .xls**：走 xlrd（但无合并信息，桥名列需本身不空）。

## 五、自动校核（每条记录带 `flags`，非空即待核）

| 检查 | 判据 | 典型成因 |
|---|---|---|
| 跨径和 ≠ 联长 | 相对误差 >2% 且 >0.05m | 跨径文本写错、漏写一跨 |
| 面积不符 | 面积 vs 联长×平均宽，偏差 >3% | 面积抄错、宽度用错 |
| 宽度异常 | 起/终点宽度比值 >2 且非分叉联 | **小数点错位**（9.048 写成 90.48） |
| 砼含量越界 | 不在 0.45~1.30 m³/m² | 砼方量填错、面积错 |
| 钢绞线越界 | kg/m² 不在 6~75；kg/m³ 不在 10~75 | 单位错（t/kg 混用） |
| 钢板越界 | kg/m² 不在 100~800 | 钢板总量与面积不匹配 |
| 钢绞线为 0 | 砼箱梁钢绞线 = 0 | 源表未填（钢箱梁不报此错） |
| 砼数量重复 | 同区块两联砼方量完全相同但面积差 >1m² | **整行复制残留** |

**统计只取 flags 为空的记录**，脏数据不污染经验值。待核记录在报告第五节单列，
逐条给出桥名、联号、源行号，便于回源表改。

## 六、真实案例（2026-10-22，武大高速汉口北互通）

表：`汉口北互通钢束含量汇总表-szh.xlsx`（现浇区块 45 联 + 钢箱梁区块 12 联）。

- 现浇预应力砼箱梁（38 条有效）：砼含量 P25/中位/P75 = **0.72 / 0.79 / 0.91** m³/m²；
  钢绞线 **17.95 / 19.96 / 35.39** kg/m²、**23.12 / 28.70 / 38.04** kg/m³。
- 按最大跨径分档（砼含量中位值）：≤20m **0.649**（n=6）、20~30m **0.797**（n=26）、
  30~40m **0.851**（n=6）——跨径越大含量越高，符合预期。
- 钢箱梁（12 条）：钢板含量中位 **607** kg/m²。
- 抓出 3 类硬错：
  1. 汉口北大道高架第 8 联（分叉2×23.25）砼数量 3478.01 与滠口高架第 1 联**完全相同**，
     面积却只有 1648m² → 砼含量 2.11 m³/m² 明显失真（应为 0.9 左右），整行复制残留；
  2. D 区第 6 联终点宽度 **90.48**（起点 9.25，非分叉）→ 小数点错位，连带面积 2493m²、
     砼含量 0.124 全部失真；按 9.048 修正后面积约 457m²、含量 0.68 即正常；
  3. C 区 3 联（3×18.5、2×18.5）钢绞线全为 0，需确认是否无预应力或漏填。

**通用性验证**：同目录 `武大高速互通桥梁钢束含量汇总表（青峰互通）.xls`
（单宽度列、老 .xls 格式）直接跑通——26 条、**0 条待核**，跳过 8 行占位行，
中位 砼 0.65 m³/m²、钢绞线 19.02 kg/m² / 29.69 kg/m³，与汉口北口径一致。

## 七、二次检索（问经验值时怎么做）

不用重新读 Excel，直接查库：

```bash
# 按结构类型统计（JSON 里 stats 字段也可直接用）
python -c "
import json;rs=json.load(open('<skill>/data/box_girder_indicators.json',encoding='utf-8'))
for r in rs:
    if not r['flags'] and r['struct_type']=='现浇箱梁' and r['max_span'] and 25<=r['max_span']<=35:
        print(r['bridge'],r['span_raw'],r['conc_ratio'],r['strand_m2'],r['strand_m3'])
"
```

回答用户时给**区间 + 中位值 + 样本数**，不要只给单值；样本 <5 条要说明"样本偏少，仅供参考"。
对比本项目时，先算本项目的三项指标，再和同跨径档位的中位值并列，给出偏离百分比。

## 八、扩展与维护

- **换一种表头**：改 `HEADER_KEYS` 里的关键字（脚本顶部，按精确度从高到低排列），
  或直接加别名，不必改逻辑；
- **阈值不合口味**：改 `RANGE`、`TOL_LEN`、`TOL_AREA`、`WIDTH_RATIO`；
- **新区块类型**（如"预制小箱梁""钢混组合梁"）：改 `guess_struct_type()` 的标题关键字；
- **重跑同文件**：按 (源文件, sheet, 行号) 去重，**后来者覆盖**，直接重跑即可，
  不会产生重复记录；
- **清库重建**：删掉 `data/box_girder_indicators.json` 再跑。
- **名称改代号**（对外分享时脱敏）：改脚本顶部 `NAME_ALIAS`，如
  `{"武大高速": "WD高速", "武大": "WD", "汉口北": "HKB"}`。入库时自动替换
  `project` / `route` / `bridge` / `block`；CSV 与 HTML 看板（含内嵌数据）也走替换。
  **长词必须排在短词前**（否则"武大高速"会先被"武大"吃掉）。
  例外：`source_file` 在 JSON 里保留真实文件名以便回表，仅 MD 待核清单使用它；
  改映射后重跑一次即可全量生效。
- **互通名与桥名拼音首字母**：脚本顶部 `BRIDGE_PINYIN = True` 默认开启，`--no-pinyin` 可关闭。
  按汉字拼音首字母代号化（`喻家咀` → `YJJ`、`滠口高架` → `SKGJ`、`主线右幅桥` → `ZXYFQ`），
  已含拉丁字母/数字的部分原样保留（`C1-2` 仍为 `C1-2`）。转换**幂等**，重跑不会二次缩写。
  判重范围：**互通名全库判重，桥名互通内判重**。
  缩写撞车时自动加 `-2` / `-3` 后缀；个别多音字可在 `BRIDGE_CODE_FIX` 里登记覆盖。
  依赖 `pypinyin`（未安装时自动跳过，保留原名）。
  记录里保留 `route_src` / `bridge_src` 两个**原始中文名**字段，报告第七节据此生成代号对照表；
  这两个字段在 HTML 看板里会被剥除，页面源码不泄露原名。**该对照表是找回原名的唯一钥匙，别删。**
  注意：代号化后想还原原名，只能删库重建（删除 `data/box_girder_indicators.json`
  与 `data/name_code_map.json` 后重跑原始 Excel）。

更多口径细节、校核阈值来由、常见坑见
`references/指标口径与校核规则.md`。
